# ⚡ ResumeForge - Dynamic & ATS-Friendly Resume Builder

**ResumeForge** is a fully dynamic, browser-based resume builder web application designed to help developers and job seekers create professional, ATS-compliant resumes in minutes. With custom themes, live accent color pickers, draggable dynamic sections, and instant PDF export, building a resume has never been smoother.

---

## ✨ Features

- 🎨 **10 Pro Structural Layout Themes**: Choose from Modern Classic, Left/Right Split Sidebar (30/70 & 70/30), Minimalist, Tech Hero Banner, Vertical Timeline, Grid Compact, and more.
- 🎨 **Custom Theme Accent Color**: Real-time color picker to customize resume primary headings and sidebar backgrounds.
- 📸 **Optional Profile Photo**: Upload your photo with two custom shape options: **Circle** 🔵 or **Square** 🔲.
- 🖐️ **Drag & Drop Section Reordering**: Easily reorder sections (Education, Experience, Projects, Skills, Custom Sections) on the fly.
- ➕ **Dynamic Section Management**: Add, delete, or re-order dynamic entry items and create entirely new custom sections (e.g., Certifications, Awards, Languages).
- 🔤 **ATS-Friendly Fonts**: Choose from top sans-serif, serif, and monospace Developer fonts (Calibri, Inter, Garamond, Fira Code, etc.).
- 🖨️ **Instant PDF Export**: Print or save directly as a clean PDF formatted specifically for standard A4 resume output.
- 🔒 **100% Private & Local**: All data processing and image rendering happen entirely inside your browser. No server storage.

## 🛠️ Tech Stack

- **HTML5**: Semantic layout and form structure.
- **CSS3**: Custom CSS variables, Flexbox, CSS Grid layouts, responsive designs, and `@media print` rules.
- **JavaScript (ES6+)**: DOM manipulation, dynamic HTML generation, File API (FileReader), Drag-and-Drop API, and state rendering.
